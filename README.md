## Repository initialization

This repository is being initialized for the documentation and governance foundation requested by the project owner. No application source, production installer, certified operating-system support, or release is included in this initial commit.

The supplied Foundation v0.6 and v0.7 archives are development inputs, not GitHub releases. Their provenance and limitations will be documented on a dedicated feature branch before any source import.

The documentation work will use `features/*` → `develop` → `stable` → `main` → `production`. Creating these references does not publish or deploy the product.

Project licensing remains undecided. Do not infer a software license from repository access or visibility.
