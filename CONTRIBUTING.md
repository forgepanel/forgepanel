# Contributing to ForgePanel

[English contribution workflow](DOCUMENTATION/en/18-contributing/README.md) · [Contribution en français](DOCUMENTATION/fr/18-contributing/README.md)

Start with [AGENTS.md](AGENTS.md), which applies to both AI and human technical contributors. Read the current status before implementing planned components. The initial repository is documentation-only; source archives remain separate inputs until a reviewed import.

Use a focused `features/*` branch and a PR into `develop`. Explain the need, scope, acceptance criteria, actual checks, security implications, migrations and rollback. Update both documentation languages and the central changelog. Do not bypass protected-branch reviews or label your own review independent.

License and contribution terms are not yet selected. Do not add third-party code or dependencies whose redistribution terms have not been assessed. Report missing permissions and product decisions clearly; do not delegate programming or code review to the project owner.
